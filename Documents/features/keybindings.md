# Eede キーボードショートカット一覧・操作ガイド (Keybindings Reference)

Eede (Excellent Expert Dot Editor) は、ドット絵制作の作業効率を極限まで高めるため、**EDGE2** および **Aseprite** の優れた操作体系を融合したハイブリッドなキーボードショートカットを採用しています。

直感的な単一文字キーによるツール切り替えから、確実で安全な修飾キー付きの幾何学変形・ドック連携まで、すべての操作をキーボードからスムーズに実行できます。

---

## 1. 基本操作・ファイル・クリップボード (Basic & File Operations)

| 操作 | ショートカットキー | 説明 |
| :--- | :--- | :--- |
| **元に戻す (Undo)** | `Ctrl + Z` | 直前の描画・変形・ドック操作を取り消します |
| **やり直し (Redo)** | `Ctrl + Y` / `Ctrl + Shift + Z` | 取り消した操作をやり直します |
| **新規作成** | `Ctrl + N` | 新規キャンバス作成ダイアログを開きます |
| **開く** | `Ctrl + O` | 画像ファイル（PNG / BMP / ARV）を開きます |
| **上書き保存** | `Ctrl + S` | 現在の画像を上書き保存します |
| **名前を付けて保存** | `Ctrl + Shift + S` | 新しい名前を付けて画像を保存します |
| **コピー** | `Ctrl + C` | 選択範囲（未選択時はキャンバス全体）をクリップボードにコピーします |
| **切り取り** | `Ctrl + X` | 選択範囲を切り取ってクリップボードに保存します |
| **貼り付け** | `Ctrl + V` | クリップボードの画像をキャンバスに貼り付けます（フローティング選択） |
| **選択解除** | `Esc` / `Ctrl + D` | 選択範囲を確定・解除します |
| **タブ（画像）を閉じる** | `Ctrl + W` | 現在開いているタブを閉じます（未保存時は確認ダイアログ表示） |

## 2. 描画ツール切り替え (Drawing Tools)

文字入力中（テキストボックス等）以外の通常時に、キーを押すだけで即座に描画ツールを切り替えられます。

| ツール | ショートカットキー | 対応エイリアス / 説明 |
| :--- | :--- | :--- |
| **自由曲線 (ペン/ブラシ)** | `B` / `P` | `B` (Brush) / `P` (Pen) の双方に対応 |
| **領域選択 (矩形選択)** | `M` / `S` | `M` (Marquee) / `S` (Select) の双方に対応 |
| **直線** | `L` | 直線描画ツール (Line) |
| **塗りつぶし (バケツ)** | `G` / `F` | `G` (Bucket) / `F` (Fill) の双方に対応 |
| **矩形 (枠線)** | `U` / `R` | `U` (Shape) / `R` (Rectangle) の双方に対応 |
| **矩形 (塗りつぶし)** | `Shift + U` / `Shift + R` | 内部を塗りつぶす矩形を描画 |
| **円 (枠線)** | `C` | 楕円・円描画ツール (Circle) |
| **円 (塗りつぶし)** | `Shift + C` | 内部を塗りつぶす円を描画 |

> **💡 直線・正方形の比率固定**:
> 直線・矩形・円の描画中に `Shift` キーを押しながらドラッグすると、水平・垂直・45度の直線や正方形・真円にスナップされます。

## 3. カラー＆ブラシ・ペンサイズ (Color & Brush)

| 操作 | ショートカットキー | 説明 |
| :--- | :--- | :--- |
| **描画色と背景色の交換** | `X` | 現在の前景色と背景色をワンキーでスワップします |
| **デフォルト色リセット** | `D` | 前景色を「黒」、背景色を「白」にリセットします |
| **ペンサイズ拡大 (+1px)** | `]` | ペン先・ブラシサイズを 1px 大きくします |
| **ペンサイズ縮小 (-1px)** | `[` | ペン先・ブラシサイズを 1px 小さくします |
| **ペンサイズ 1px** | `Shift + 1` | ペンサイズを即座に 1px に設定 |
| **ペンサイズ 3px** | `Shift + 2` | ペンサイズを即座に 3px に設定 |
| **ペンサイズ 6px** | `Shift + 3` | ペンサイズを即座に 6px に設定 |
| **即時スポイト (カラーピック)** | `右クリック` | キャンバス上を右クリックした位置のピクセル色を取得します |

## 4. 変形・幾何学操作 (Transformations & Actions)

選択範囲がある場合は「選択範囲内のみ」、ない場合は「キャンバス全体」に対して適用されます。

| 操作 | ショートカットキー | 説明 |
| :--- | :--- | :--- |
| **1px シフト (上/下/左/右)** | `↑` / `↓` / `←` / `→` | ピクセルを矢印キー方向に 1 ピクセル移動します |
| **左右反転 (水平反転)** | `Shift + H` | 画像を左右逆にひっくり返します |
| **上下反転 (垂直反転)** | `Shift + V` | 画像を上下逆にひっくり返します |
| **右90度回転 (時計回り)** | `Ctrl + R` | 時計回りに 90 度回転します |
| **左を右に鏡面コピー** | `Alt + H` | 画像の左半分を右半分に反転して複製します（左右対称ドットに最適） |
| **上を下に鏡面コピー** | `Alt + V` | 画像の上半分を下半分に反転して複製します |
| **拡大縮小ダイアログ** | `Ctrl + T` | 最近傍法による拡大縮小・リサイズダイアログを開きます |
| **強アンチエイリアス** | `Ctrl + Alt + A` | 1ピクセル単位で強力に平滑化します |
| **弱アンチエイリアス** | `Ctrl + Shift + Alt + A` | 2倍オーバーサンプリングで繊細に平滑化します |

## 5. 表示・ズーム・パン・グリッド・透過 (View & Navigation)

### キーボードショートカット

| 操作 | ショートカットキー | 説明 |
| :--- | :--- | :--- |
| **ズーム倍率変更 (1x〜12x)** | `1` 〜 `6` | `1`=1x, `2`=2x, `3`=4x, `4`=6x, `5`=8x, `6`=12x |
| **ズームイン (拡大)** | `Ctrl + +` / `Ctrl + ;` | 表示倍率を一段階拡大します |
| **ズームアウト (縮小)** | `Ctrl + -` | 表示倍率を一段階縮小します |
| **原寸表示 (100%)** | `Ctrl + 0` | ズーム倍率を 1x (原寸) にリセットします |
| **1px ピクセルグリッド切替** | `Ctrl + '` / `Shift + G` | 拡大時の 1px 単位のグリッド線の表示/非表示を切り替えます |
| **カーソルグリッド切替** | `Ctrl + ;` / `Alt + G` | チップ単位のカーソルグリッド表示を切り替えます |
| **透過モード切替** | `Alt + T` | 背景色ピクセルの透過表示モードを切り替えます |

### マウス・ナビゲーション操作 (Zoom & Pan)

キャンバス（編集エリア）およびドック（タイルシート表示エリア）の双方で、標準的な直感ナビゲーションに対応しています。フォーカスを切り替えることなく、**マウスカーソルが乗っているエリア**が即座に操作対象となります。

| 操作 | マウス / キー入力 | 説明 |
| :--- | :--- | :--- |
| **カーソル位置追従ズーム** | `Ctrl + マウスホイール` | カーソル直下のピクセル位置を維持したまま直感的に拡大・縮小します（倍率ステップ: 1x, 2x, 4x, 6x, 8x, 12x） |
| **画面パン (視点移動)** | `中ボタンドラッグ` (ホイール押し込み) | キャンバスやドック内を掴んで自由にスクロール移動します |
| **手のひらツール (パン)** | `Space + 左ドラッグ` | `Space` キー押下中はカーソルが手のひらに変わり、描画を行わずに画面をパン移動できます |
| **縦スクロール** | `マウスホイール回転` | 上下に通常スクロールします |
| **横スクロール** | `Shift + マウスホイール` | 左右に横スクロールします |

## 6. ワークエリア (ドック) 連携＆レイヤースタイル (Workflow & Dock)

Eede 特有の「タイルシート/ドック画像」と「メイン編集キャンバス」の連携操作です。

| 操作 | ショートカットキー | 説明 |
| :--- | :--- | :--- |
| **ドックへ転送 (Push)** | `Ctrl + Enter` | ドック側の選択枠位置に、メインキャンバスの内容を書き戻します |
| **ドックから読込 (Pull)** | `F5` | ドック枠の位置から画像をメインキャンバスに再読み込みします |
| **RGBレイヤースタイル** | `F1` | RGB成分のみを反映する描画モードに切り替えます |
| **Alphaレイヤースタイル** | `F2` | アルファ値（透明度）のみを反映する描画モードに切り替えます |
| **ARGBレイヤースタイル** | `F3` | 通常の ARGB 全成分を描画するモードに切り替えます |
| **ドック枠サイズ縮小** | `Ctrl + [` | ドックの切り出しサイズ（チップ単位）を小さくします |
| **ドック枠サイズ拡大** | `Ctrl + ]` | ドックの切り出しサイズ（チップ単位）を大きくします |

## 8. 安全設計と入力保護 (Safety & Focus Guard)

Eede のキーバインドシステムは、快適性と安全性を両立するために以下の保護設計が施されています：

1. **TextBox 入力中の完全保護**:
   - ペンサイズ入力欄やファイル名編集時など、テキスト入力コントロールにフォーカスがある間は、単一文字キー（`B`, `P`, `X`, `1`〜`6` など）が誤爆せず、通常の文字入力として安全に入力できます。
2. **破壊的操作の修飾キー必須化**:
   - 画面の反転や回転などの破壊的操作には `Shift` や `Ctrl` などの修飾キーを必須とし、ナビゲーション操作（手のひらツールや移動）の誤操作による描画破壊を防止しています。
